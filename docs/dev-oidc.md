# Local OIDC Development

`bun run dev:local:up` starts a local [Pocket ID](https://github.com/pocket-id/pocket-id) instance (port 1411) alongside the standard postgres and worker containers. After Pocket ID is healthy, the `pocket-id-seeder` container runs `scripts/dev/seed-pocketid.sh`, which:

- Creates three user groups: `homelab-admins`, `homelab-operators`, `homelab-viewers`
- Creates three dev users: `dev-admin`, `dev-operator`, `dev-viewer`
- Registers an OIDC client (`homelab-manager-dev`) with the correct callback and logout URLs
- Rotates the client secret
- Writes two output files (see below)

## Output files

**`.env.development.local`** is written (or overwritten) automatically. It sets `AUTH_ENABLED=true` and all `OIDC_*` variables so `bun dev` picks them up via Vite's env file loading. Do not edit this file; any manual changes will be overwritten the next time the seeder runs.

**`data/dev-oidc-logins.txt`** contains one-time login URLs (valid 30 days) for each dev user:

```text
admin (role: admin):
  http://localhost:1411/lc/<token>

dev-operator (role: operator):
  http://localhost:1411/lc/<token>

dev-viewer (role: viewer):
  http://localhost:1411/lc/<token>
```

Open any URL in a browser to log in as that user. Each token is single-use; once consumed, logging out and back in uses normal username/password flow via Pocket ID at `http://localhost:1411`.

## Dev users and roles

| Username | Role | Pocket ID group |
|---|---|---|
| `dev-admin` | admin | `homelab-admins` |
| `dev-operator` | operator | `homelab-operators` |
| `dev-viewer` | viewer | `homelab-viewers` |

Role mapping is controlled by `OIDC_ROLE_ADMIN`, `OIDC_ROLE_OPERATOR`, and `OIDC_ROLE_VIEWER` in `.env.development.local`.

## Refreshing login tokens

Login tokens expire or get consumed. To generate new ones:

```bash
bun run dev:local:restart
```

This recreates the seeder container, which runs the seed script again and overwrites `data/dev-oidc-logins.txt` with fresh tokens.

## Cleaning up

```bash
bun run dev:local:wipe
```

This stops all containers and deletes all volumes, including the Pocket ID data volume (`pocketid-data`). The next `dev:local:up` will re-seed from scratch.

## Opting out

To skip Pocket ID entirely, remove `oidc` from `COMPOSE_PROFILES` in your `.env`:

```env
COMPOSE_PROFILES="management"
```

Without the `oidc` profile, `.env.development.local` will not be generated and auth will be disabled (the default when `AUTH_ENABLED` is unset).
