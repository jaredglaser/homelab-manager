1. Data Flow — Event-Driven Stack Status

Architecture: Worker → DB → NOTIFY → SSE → UI
Worker (30s poll)
→
Agent /stacks/status
→
Upsert stack_status table
→
NOTIFY stack_change
→
SSE /api/stack-status
→
UI updates
Deploy pipeline also triggers NOTIFY after status changes → instant UI refresh on deploy

6. Summary of All Changes

Backend
  • New stack_status DB table + NOTIFY trigger
  • Worker: StackStatusCollector polls agent every 30s
  • SSE endpoint: /api/stack-status
  • Sync status computed from deploy_history vs HEAD
  • OpenBao read/write server functions for variables
  • Stack create/delete server functions
  • Git post-receive → deploy pipeline wiring
Frontend
  • StackRow: container status summary column
  • StackDetail: container list with status + icons
  • VariablesPanel: eye toggle → lazy fetch from OpenBao
  • DeployHistoryList: per-deploy rollback buttons
  • Rollback confirmation dialog
  • Create Stack dialog + button
  • Delete Stack dialog (unmanage vs teardown)
  • SSE hook for live stack status updates
